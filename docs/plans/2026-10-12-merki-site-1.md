# Merki: Site 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Site 1 of merki.lucaslima.design: the showcase home page (hero, icon wall, icon browser, six live craft cards), the icon drawer with a prerendered page per icon, the guide and the changelog, in light and cool-slate dark, desktop and phone.

**Architecture:** The existing `site/` workspace (Vite 7 + React 19) becomes the real site. A tiny in-house router maps paths to pages. The build renders every route to static HTML with `react-dom/server` (`src/entry-server.tsx` + `site/prerender.ts`), and the client hydrates it (`src/entry-client.tsx`). Icon data comes from the build's `site/src/data/icons.json` plus `icons/_set.json`; icons render through the real `merki-icons` components, aliased to `packages/merki/src/index.ts`. `/lab` stays as a dev-only page.

**Tech Stack:** Node ≥ 22, npm workspaces, TypeScript 5.9, Vite 7, React 19, vitest 3 + @testing-library/react + jsdom (all already installed), plus one new dependency: `@fontsource-variable/inter`.

**Spec:** `docs/specs/2026-10-10-merki-design.md`, §6 (Site) is the authority. §2 (icon rules, keylines) and §5 (package API) are referenced. The approved mocks are in `docs/site-mocks/`: `01-hero-and-drawer.html` (hero at top; drawer option 1), `02-browser-first.html` (option 1 "Browser first"), `03-dark-and-mobile.html` (option 2 "Cool slate" + the three phones), `04-craft-cards.html` (the six live cards; their logic is in `craft-cards.mjs`). Open them in a browser when a visual value isn't spelled out here.

## Global Constraints

- **Never run Python** (`python`, `python3`). Use node/tsx or the Edit tool. Before reporting, make sure no process you started is still running.
- **Gate on real exit codes.** Run `npm test`, `npm run typecheck` and builds without piping through `grep`/`head`; read the full output and the exit code.
- **Prerequisite for tests, typecheck and the site build:** `npm run build:icons` (it generates `site/src/data/icons.json`, `packages/merki/src/icons/*` and `packages/merki/src/index.ts`, which are git-ignored). Run it once at the start of every task.
- **Only one new dependency:** `@fontsource-variable/inter` (installed in Task 3). No router, markdown, CSS or UI libraries.
- **CSS is imported only from `site/src/entry-client.tsx`** (via `styles/index.css`). Components never import CSS, so the SSR build never sees CSS.
- **No `window`, `document` or `localStorage` during render.** Only in effects and event handlers. Server HTML and the first client render must be identical (Task 9 tests this).
- **Storage:** every `localStorage` access goes through `site/src/lib/storage.ts` (`safeGet`/`safeSet`, try/catch). Keys: `merki-theme` (`'light' | 'dark'`), `merki-size` (`'16' | '20' | '24'`).
- **Blue (`--blue`) means "how it's built":** keylines, anchor points, handles, the highlighted icons in the wall band, the Keylines/Points toggles in the drawer, and the Icons section glyph. Nothing else is blue: no blue links, buttons, focus rings or category chips. Section glyphs: Icons blue, Craft orange, Guide pink.
- **Copy is verbatim.** Hero text, card lines and empty states are written exactly as given in the tasks. Sentence case. No exclamation marks.
- **Motion:** only where something changes place (drawer, sheet, card demos on interaction). Fast, ease-out (`--ease: cubic-bezier(.2,.8,.2,1)`). Nothing animates on scroll. `prefers-reduced-motion: reduce` turns transitions and animations off.
- **Stable strings that tests across tasks rely on:** the home page contains `157 icons for software`; the drawer is `<aside aria-label="<name> icon">` with an `<h2>` holding the name; an unknown icon page says `There's no icon called “<name>”.`; each guide page has an `<h1>` with its title.
- **Breakpoint:** phone layout below 768px (`@media (max-width: 767px)`). 16px side gutter on phones, no horizontal page scroll.
- Never trace or copy other icon sets' artwork. The site only shows Merki icons.
- Lucas runs PowerShell 5.1. Any command you hand to him uses Windows paths and no `&&`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A path that isn't a page** (`/icons/nope`, `/icons/`, `/guide/x`, `/lab` in production): renders the not-found page with status 404 and a way back. It never shows a blank page or crashes. Tests: Task 1 (`matchRoute`), Task 2 (`render('/icons/nope')`).
2. **Storage blocked** (Safari private mode, cookies off, `localStorage` getter throws): the page renders with defaults (system theme, size 16), and the theme toggle and size switch still work for the page view. Tests: Task 3 (theme), Task 5 (size).
3. **Clipboard unavailable or denied:** the copy button says `Couldn't copy` for 1.2s. It never shows ✓ when nothing was copied. Test: Task 7.
4. **Search input people actually type:** uppercase, extra spaces, two words (`arrow up`), a tag (`pulse`), a component name (`CalendarIcon`), or nothing that matches. Expected: sensible matches, and an honest empty state with a "Clear search" button. Tests: Task 5.
5. **Hydration:** stored prefs (size 24, dark theme) must not cause hydration mismatches. They apply after hydration. Test: Task 9.

```ts
import set from '../../../icons/_set.json';
import { CATEGORY_ORDER } from '../lab/types';
import raw from './icons.json';

export type Category = (typeof CATEGORY_ORDER)[number];

/** One icon as the build writes it to icons.json. `svg` is the optimized SVG without width/height. */
export interface SiteIcon {
  name: string;
  component: string;
  category: Category;
  tags: string[];
  aliases: string[];
  svg: string;
}

export interface CategoryGroup {
  id: Category;
  label: string;
  icons: SiteIcon[];
}

export const icons = raw as unknown as SiteIcon[];
export const iconByName: ReadonlyMap<string, SiteIcon> = new Map(icons.map((icon) => [icon.name, icon]));
export const categoryLabel = (id: Category): string => id.charAt(0).toUpperCase() + id.slice(1);

const manifest = set as Record<Category, string[]>;

export const categories: CategoryGroup[] = CATEGORY_ORDER.map((id) => ({
  id,
  label: categoryLabel(id),
  icons: manifest[id].map((name) => {
    const icon = iconByName.get(name);
    if (!icon) throw new Error(`icons/_set.json lists ${name}, but the build has no such icon`);
    return icon;
  }),
}));

/** Every icon once: category order, then the order inside icons/_set.json. */
export const orderedIcons: SiteIcon[] = categories.flatMap((group) => group.icons);
```

```ts
export const GUIDE_PAGES = [
  { slug: 'install', title: 'Install', description: 'Install merki-icons from npm, pnpm, yarn or bun.' },
  { slug: 'react', title: 'React', description: 'The Merki React components: size, color, absoluteStrokeWidth and title.' },
  { slug: 'svg', title: 'SVG', description: 'Use Merki without React: plain currentColor SVGs, copied, downloaded or taken from the package.' },
  { slug: 'accessibility', title: 'Accessibility', description: 'Merki icons are decorative by default. How to name them, and how to label icon-only buttons.' },
] as const;

export type GuideSlug = (typeof GUIDE_PAGES)[number]['slug'];

export type Route =
  | { kind: 'home' }
  | { kind: 'icon'; name: string }
  | { kind: 'guide'; slug: GuideSlug }
  | { kind: 'changelog' }
  | { kind: 'notfound'; missingIcon?: string };

export function normalizePath(path: string): string {
  const clean = path.split(/[?#]/)[0] || '/';
  if (clean === '/') return clean;
  return clean.replace(/\/+$/, '') || '/';
}

export function matchRoute(path: string, names: { has(name: string): boolean }): Route {
  const p = normalizePath(path);
  if (p === '/') return { kind: 'home' };
  if (p === '/changelog') return { kind: 'changelog' };
  const icon = /^\/icons\/([a-z0-9-]+)$/.exec(p);
  if (icon) return names.has(icon[1]) ? { kind: 'icon', name: icon[1] } : { kind: 'notfound', missingIcon: icon[1] };
  const guide = /^\/guide\/([a-z-]+)$/.exec(p);
  const page = guide ? GUIDE_PAGES.find((g) => g.slug === guide[1]) : undefined;
  if (page) return { kind: 'guide', slug: page.slug };
  return { kind: 'notfound' };
}

export function allPaths(names: Iterable<string>): string[] {
  return ['/', ...[...names].map((name) => `/icons/${name}`), ...GUIDE_PAGES.map((g) => `/guide/${g.slug}`), '/changelog'];
}

export interface Head {
  title: string;
  description: string;
  canonical: string;
}

const HOME_DESCRIPTION =
  'merki-icons is a growing collection of bold, rounded icons for Figma and code. Open source and free to use under the MIT License.';

export function headFor(route: Route, path: string, count: number, siteUrl: string): Head {
  const p = normalizePath(path);
  const canonical = `${siteUrl}${p}`;
  switch (route.kind) {
    case 'home':
      return { title: `Merki · ${count} icons for software people use all day`, description: HOME_DESCRIPTION, canonical };
    case 'icon':
      return {
        title: `${route.name} icon · Merki`,
        description: `The ${route.name} icon from Merki, drawn on a 16px grid with one stroke. Copy the SVG or the React component. MIT.`,
        canonical,
      };
    case 'guide': {
      const page = GUIDE_PAGES.find((g) => g.slug === route.slug)!;
      return { title: `${page.title} · Merki guide`, description: page.description, canonical };
    }
    case 'changelog':
      return { title: 'Changelog · Merki', description: 'What changed in Merki, release by release.', canonical };
    case 'notfound':
      return { title: 'Not found · Merki', description: 'There is no page here.', canonical };
  }
}

const escapeHtml = (value: string): string =>
  value.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');

export function headTags(head: Head): string {
  const title = escapeHtml(head.title);
  const description = escapeHtml(head.description);
  return [
    `<title>${title}</title>`,
    `<meta name="description" content="${description}">`,
    `<link rel="canonical" href="${escapeHtml(head.canonical)}">`,
    `<meta property="og:title" content="${title}">`,
    `<meta property="og:description" content="${description}">`,
    `<meta property="og:url" content="${escapeHtml(head.canonical)}">`,
  ].join('\n    ');
}
```

```tsx
import {
  createContext,
  useCallback,
  useContext,
  useEffect,
  useMemo,
  useState,
  type AnchorHTMLAttributes,
  type MouseEvent,
  type ReactNode,
} from 'react';
import { normalizePath } from './routes';

export interface NavigateOptions {
  replace?: boolean;
  state?: unknown;
}

interface RouterValue {
  path: string;
  hash: string;
  /** Bumps on every navigation, so effects can react to "same path, new hash". */
  key: number;
  navigate: (to: string, options?: NavigateOptions) => void;
}

const RouterContext = createContext<RouterValue | null>(null);

function split(to: string): { path: string; hash: string } {
  const i = to.indexOf('#');
  if (i === -1) return { path: normalizePath(to), hash: '' };
  return { path: normalizePath(to.slice(0, i) || '/'), hash: to.slice(i + 1) };
}

export function scrollToId(id: string): void {
  document.getElementById(id)?.scrollIntoView?.({ block: 'start' });
}

export function RouterProvider({ initialPath, children }: { initialPath: string; children: ReactNode }) {
  const [location, setLocation] = useState(() => ({ ...split(initialPath), key: 0 }));

  useEffect(() => {
    const onPop = () =>
      setLocation((prev) => ({
        path: normalizePath(window.location.pathname),
        hash: window.location.hash.slice(1),
        key: prev.key + 1,
      }));
    window.addEventListener('popstate', onPop);
    return () => window.removeEventListener('popstate', onPop);
  }, []);

  const navigate = useCallback((to: string, options: NavigateOptions = {}) => {
    const next = split(to);
    const url = next.hash ? `${next.path}#${next.hash}` : next.path;
    if (options.replace) window.history.replaceState(options.state ?? null, '', url);
    else window.history.pushState(options.state ?? null, '', url);
    setLocation((prev) => ({ ...next, key: prev.key + 1 }));
  }, []);

  const value = useMemo(() => ({ ...location, navigate }), [location, navigate]);
  return <RouterContext.Provider value={value}>{children}</RouterContext.Provider>;
}

export function useRouter(): RouterValue {
  const value = useContext(RouterContext);
  if (!value) throw new Error('useRouter needs a RouterProvider');
  return value;
}

type LinkProps = AnchorHTMLAttributes<HTMLAnchorElement> & { to: string; onNavigate?: () => void };

export function Link({ to, onNavigate, onClick, ...rest }: LinkProps) {
  const { path, navigate } = useRouter();
  const handle = (event: MouseEvent<HTMLAnchorElement>) => {
    onClick?.(event);
    if (event.defaultPrevented || event.button !== 0 || event.metaKey || event.ctrlKey || event.shiftKey || event.altKey) return;
    event.preventDefault();
    onNavigate?.();
    const next = split(to);
    if (next.path === path && next.hash) {
      window.history.replaceState(window.history.state, '', `${next.path}#${next.hash}`);
      scrollToId(next.hash);
      return;
    }
    navigate(to);
  };
  return <a href={to} {...rest} onClick={handle} />;
}
```

```tsx
  // Home and an open icon are the same page: moving between them keeps the scroll position.
```

```ts
import { mkdirSync, readFileSync, writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';

export interface Rendered {
  html: string;
  head: string;
  status: number;
}

export interface PrerenderInput {
  distDir: string;
  paths: string[];
  render: (path: string) => Rendered;
  siteUrl: string;
}

export function outFile(distDir: string, path: string): string {
  if (path === '/') return join(distDir, 'index.html');
  if (path === '/404') return join(distDir, '404.html');
  return join(distDir, ...path.slice(1).split('/'), 'index.html');
}

export function fillTemplate(template: string, page: Rendered): string {
  if (!template.includes('<!--app-head-->') || !template.includes('<!--app-html-->')) {
    throw new Error('index.html is missing <!--app-head--> or <!--app-html-->');
  }
  // Function replacers: rendered HTML may contain "$&" and must be inserted as-is.
  return template.replace('<!--app-head-->', () => page.head).replace('<!--app-html-->', () => page.html);
}

export function sitemap(siteUrl: string, paths: string[]): string {
  const urls = paths.map((path) => `  <url><loc>${siteUrl}${path}</loc></url>`).join('\n');
  return `<?xml version="1.0" encoding="UTF-8"?>\n<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">\n${urls}\n</urlset>\n`;
}

export function prerender({ distDir, paths, render, siteUrl }: PrerenderInput): number {
  const template = readFileSync(join(distDir, 'index.html'), 'utf8');
  for (const path of [...paths, '/404']) {
    const page = render(path);
    const expected = path === '/404' ? 404 : 200;
    if (page.status !== expected) throw new Error(`${path} rendered with status ${page.status}, expected ${expected}`);
    const file = outFile(distDir, path);
    mkdirSync(dirname(file), { recursive: true });
    writeFileSync(file, fillTemplate(template, page));
  }
  writeFileSync(join(distDir, 'sitemap.xml'), sitemap(siteUrl, paths));
  return paths.length + 1;
}

const isMain = Boolean(process.argv[1]) && import.meta.url === pathToFileURL(process.argv[1]).href;
if (isMain) {
  const here = dirname(fileURLToPath(import.meta.url));
  const server = (await import(pathToFileURL(join(here, 'dist-server', 'entry-server.js')).href)) as {
    render: (path: string) => Rendered;
    paths: string[];
    SITE_URL: string;
  };
  const count = prerender({ distDir: join(here, 'dist'), paths: server.paths, render: server.render, siteUrl: server.SITE_URL });
  console.log(`Prerendered ${count} pages.`);
}
```

```ts
export const resolveTheme = (pref: Theme | null, systemDark: boolean): Theme => pref ?? (systemDark ? 'dark' : 'light');

export function currentTheme(root: HTMLElement = document.documentElement): Theme {
  return root.dataset.theme === 'dark' ? 'dark' : 'light';
}

export function applyTheme(theme: Theme, root: HTMLElement = document.documentElement): void {
  root.dataset.theme = theme;
}

export function toggleTheme(root: HTMLElement = document.documentElement): Theme {
  const next: Theme = currentTheme(root) === 'dark' ? 'light' : 'dark';
  applyTheme(next, root);
  safeSet(THEME_KEY, next);
  return next;
}

/** Follow the system while the visitor hasn't picked a theme. Returns the unsubscribe. */
export function watchSystemTheme(): () => void {
  if (typeof window.matchMedia !== 'function') return () => {};
  const query = window.matchMedia('(prefers-color-scheme: dark)');
  const onChange = () => {
    if (parseTheme(safeGet(THEME_KEY)) === null) applyTheme(resolveTheme(null, query.matches));
  };
  query.addEventListener?.('change', onChange);
  return () => query.removeEventListener?.('change', onChange);
}
```

```ts
import { useCallback, useEffect, useState } from 'react';

/** Copies text. Resolves true only when something was actually copied. */
export async function copyText(
  text: string,
  nav: Navigator | undefined = globalThis.navigator,
  doc: Document | undefined = globalThis.document,
): Promise<boolean> {
  try {
    if (nav?.clipboard?.writeText) {
      await nav.clipboard.writeText(text);
      return true;
    }
  } catch {
    // Denied or unavailable: try the fallback below.
  }
  if (!doc) return false;
  const area = doc.createElement('textarea');
  area.value = text;
  area.setAttribute('readonly', '');
  area.style.position = 'fixed';
  area.style.opacity = '0';
  doc.body.append(area);
  area.select();
  try {
    return doc.execCommand('copy');
  } catch {
    return false;
  } finally {
    area.remove();
  }
}

export type CopyState = 'idle' | 'copied' | 'failed';

export function useCopy(): { state: CopyState; copy: (text: string) => Promise<void> } {
  const [state, setState] = useState<CopyState>('idle');
  useEffect(() => {
    if (state === 'idle') return;
    const timer = setTimeout(() => setState('idle'), 1200);
    return () => clearTimeout(timer);
  }, [state]);
  const copy = useCallback(async (text: string) => setState((await copyText(text)) ? 'copied' : 'failed'), []);
  return { state, copy };
}
```

```ts
import type { SiteIcon } from '../data/icons';

/** Every word of the query must appear in the name, a tag, an alias or the component name. */
export function searchIcons(list: SiteIcon[], query: string): SiteIcon[] {
  const words = query.toLowerCase().trim().split(/\s+/).filter(Boolean);
  if (words.length === 0) return list;
  return list.filter((icon) => {
    const haystack = [icon.name, icon.component, ...icon.tags, ...icon.aliases].map((value) => value.toLowerCase());
    return words.every((word) => haystack.some((value) => value.includes(word)));
  });
}
```

```ts
export type NavKey = 'ArrowLeft' | 'ArrowRight' | 'ArrowUp' | 'ArrowDown' | 'Home' | 'End';
export const NAV_KEYS: ReadonlySet<string> = new Set<NavKey>(['ArrowLeft', 'ArrowRight', 'ArrowUp', 'ArrowDown', 'Home', 'End']);

/** Next icon for a key press. Groups are the visible category cards, each laid out `cols` wide. */
export function moveInGroups(groups: string[][], current: string, key: NavKey, cols: number): string {
  const flat = groups.flat();
  const g = groups.findIndex((group) => group.includes(current));
  if (g === -1) return flat[0] ?? current;
  const group = groups[g];
  const i = group.indexOf(current);
  const col = i % cols;

  switch (key) {
    case 'ArrowLeft':
      return flat[Math.max(0, flat.indexOf(current) - 1)];
    case 'ArrowRight':
      return flat[Math.min(flat.length - 1, flat.indexOf(current) + 1)];
    case 'Home':
      return group[0];
    case 'End':
      return group[group.length - 1];
    case 'ArrowDown': {
      if (i + cols < group.length) return group[i + cols];
      const lastRow = Math.floor((group.length - 1) / cols);
      if (Math.floor(i / cols) < lastRow) return group[group.length - 1];
      const next = groups[g + 1];
      return next ? next[Math.min(col, next.length - 1)] : current;
    }
    case 'ArrowUp': {
      if (i - cols >= 0) return group[i - cols];
      const prev = groups[g - 1];
      if (!prev) return current;
      const lastRowStart = Math.floor((prev.length - 1) / cols) * cols;
      return prev[Math.min(lastRowStart + col, prev.length - 1)];
    }
  }
}

/** Column count of a CSS grid, from its computed template. Falls back to 16 where there is no layout (tests). */
export function columnsOf(el: Element | null): number {
  if (!el) return 16;
  const template = getComputedStyle(el).gridTemplateColumns;
  const count = template ? template.split(' ').filter(Boolean).length : 0;
  return count > 0 ? count : 16;
}
```

```tsx
import { createContext, useCallback, useContext, useEffect, useMemo, useState, type ReactNode } from 'react';
import { safeGet, safeSet } from './storage';

export type Size = 16 | 20 | 24;
export const SIZE_KEY = 'merki-size';
export const parseSize = (value: string | null): Size => (value === '20' ? 20 : value === '24' ? 24 : 16);

interface Prefs {
  size: Size;
  setSize: (size: Size) => void;
}

const PrefsContext = createContext<Prefs>({ size: 16, setSize: () => {} });

export function PrefsProvider({ children }: { children: ReactNode }) {
  // Starts at the default on the server and on the first client render, then loads the stored value.
  const [size, setSizeState] = useState<Size>(16);
  useEffect(() => setSizeState(parseSize(safeGet(SIZE_KEY))), []);
  const setSize = useCallback((next: Size) => {
    setSizeState(next);
    safeSet(SIZE_KEY, String(next));
  }, []);
  const value = useMemo(() => ({ size, setSize }), [size, setSize]);
  return <PrefsContext.Provider value={value}>{children}</PrefsContext.Provider>;
}

export const usePrefs = (): Prefs => useContext(PrefsContext);
```

```tsx
import { SearchIcon } from 'merki-icons';
import { useEffect, useMemo, useRef, useState, type KeyboardEvent as ReactKeyboardEvent } from 'react';
import { categories, icons, orderedIcons } from '../data/icons';
import { SIZES } from '../lab/types';
import { NAV_KEYS, columnsOf, moveInGroups, type NavKey } from '../lib/grid-nav';
import { usePrefs } from '../lib/prefs';
import { Link } from '../lib/router';
import { searchIcons } from '../lib/search';
import { Icon } from './Icon';

export interface BrowserProps {
  query: string;
  onQuery: (query: string) => void;
  /** The icon whose drawer is open, if any. */
  selected: string | null;
  onOpen: (name: string) => void;
  /** Arrow keys moved while a drawer is open: the drawer follows. */
  onMove: (name: string) => void;
}

export function Browser({ query, onQuery, selected, onOpen, onMove }: BrowserProps) {
  const { size, setSize } = usePrefs();
  const inputRef = useRef<HTMLInputElement>(null);
  const gridRef = useRef<HTMLDivElement>(null);
  const [active, setActive] = useState<string | null>(selected);
  useEffect(() => {
    if (selected) setActive(selected);
  }, [selected]);

  const groups = useMemo(() => {
    const hits = new Set(searchIcons(orderedIcons, query).map((icon) => icon.name));
    return categories
      .map((group) => ({ ...group, icons: group.icons.filter((icon) => hits.has(icon.name)) }))
      .filter((group) => group.icons.length > 0);
  }, [query]);

  // One tab stop for the whole grid (roving tabindex).
  const visible = groups.flatMap((group) => group.icons.map((icon) => icon.name));
  const tabStop = active && visible.includes(active) ? active : (visible[0] ?? null);

  useEffect(() => {
    const onKey = (event: KeyboardEvent) => {
      const typing = event.target instanceof HTMLElement && event.target.closest('input, textarea, [contenteditable="true"]');
      if ((event.key === 'k' && (event.metaKey || event.ctrlKey)) || (event.key === '/' && !typing)) {
        event.preventDefault();
        inputRef.current?.focus();
      }
    };
    document.addEventListener('keydown', onKey);
    return () => document.removeEventListener('keydown', onKey);
  }, []);

  const onGridKey = (event: ReactKeyboardEvent<HTMLDivElement>) => {
    if (!NAV_KEYS.has(event.key)) return;
    const cell = (event.target as HTMLElement).closest<HTMLElement>('[data-name]');
    if (!cell?.dataset.name) return;
    event.preventDefault();
    const next = moveInGroups(
      groups.map((group) => group.icons.map((icon) => icon.name)),
      cell.dataset.name,
      event.key as NavKey,
      columnsOf(cell.parentElement),
    );
    setActive(next);
    gridRef.current?.querySelector<HTMLElement>(`[data-name="${next}"]`)?.focus();
    if (selected && next !== selected) onMove(next);
  };

  return (
    <div className="browser">
      <div className="toolbar">
        <label className="search">
          <SearchIcon size={15} />
          <input
            ref={inputRef}
            type="search"
            aria-label="Search icons"
            placeholder={`Search ${icons.length} icons`}
            value={query}
            onChange={(event) => onQuery(event.target.value)}
            onKeyDown={(event) => {
              if (event.key === 'Escape' && query) {
                event.stopPropagation();
                onQuery('');
              }
            }}
          />
          <kbd aria-hidden="true">/</kbd>
        </label>
        <div className="seg" role="group" aria-label="Icon size">
          {SIZES.map((s) => (
            <button key={s} type="button" aria-pressed={size === s} onClick={() => setSize(s)}>
              {s}
            </button>
          ))}
        </div>
        <nav className="chips" aria-label="Categories">
          <Link to="/#icons">All</Link>
          {categories.map((group) => (
            <Link key={group.id} to={`/#cat-${group.id}`}>{group.label}</Link>
          ))}
        </nav>
      </div>

      <div ref={gridRef} onKeyDown={onGridKey}>
        {groups.length === 0 ? (
          <div className="empty">
            <p>No icons match “{query.trim()}”.</p>
            <button
              type="button"
              className="ctl"
              onClick={() => {
                onQuery('');
                inputRef.current?.focus();
              }}
            >
              Clear search
            </button>
          </div>
        ) : (
          groups.map((group) => (
            <section key={group.id} id={`cat-${group.id}`} className="cat" aria-labelledby={`cat-${group.id}-title`}>
              <h3 className="cat-h" id={`cat-${group.id}-title`}>
                {group.label} <span>{group.icons.length}</span>
              </h3>
              <div className="grid" data-size={size}>
                {group.icons.map((icon) => (
                  <button
                    key={icon.name}
                    type="button"
                    className="cell"
                    data-name={icon.name}
                    aria-label={icon.name}
                    aria-current={selected === icon.name ? 'true' : undefined}
                    tabIndex={icon.name === tabStop ? 0 : -1}
                    onFocus={() => setActive(icon.name)}
                    onClick={() => onOpen(icon.name)}
                  >
                    <Icon component={icon.component} size={size} />
                  </button>
                ))}
              </div>
```

```ts
export type Pt = readonly [number, number];
/** A curve handle: the anchor it belongs to, then the control point. */
export type Handle = readonly [number, number, number, number];
export interface Points {
  anchors: Pt[];
  handles: Handle[];
}

const TOKEN = /[a-zA-Z]|-?(?:\d+\.?\d*|\.\d+)(?:e-?\d+)?/g;

export function pathPoints(d: string): Points {
  const tokens = d.match(TOKEN) ?? [];
  const anchors: Pt[] = [];
  const handles: Handle[] = [];
  let i = 0;
  let cx = 0, cy = 0, sx = 0, sy = 0;
  let cmd = '';
  let lastCtrl: Pt | null = null;
  const fail = (): never => {
    throw new Error(`can't read path data: ${d}`);
  };
  const num = (): number => {
    const value = Number(tokens[i++]);
    return Number.isFinite(value) ? value : fail();
  };

  while (i < tokens.length) {
    if (/^[a-zA-Z]$/.test(tokens[i])) cmd = tokens[i++];
    else if (!cmd) fail();
    const C = cmd.toUpperCase();
    const rel = cmd !== C;
    const ox = rel ? cx : 0;
    const oy = rel ? cy : 0;

    switch (C) {
      case 'Z':
        cx = sx;
        cy = sy;
        lastCtrl = null;
        cmd = ''; // numbers straight after Z are invalid
        continue;
      case 'M':
        cx = ox + num();
        cy = oy + num();
        sx = cx;
        sy = cy;
        anchors.push([cx, cy]);
        cmd = rel ? 'l' : 'L'; // further pairs are line-tos
        lastCtrl = null;
        continue;
      case 'L':
        cx = ox + num();
        cy = oy + num();
        break;
      case 'H':
        cx = (rel ? cx : 0) + num();
        break;
      case 'V':
        cy = (rel ? cy : 0) + num();
        break;
      case 'C':
      case 'S': {
        let x1: number, y1: number;
        if (C === 'C') {
          x1 = ox + num();
          y1 = oy + num();
        } else {
          x1 = lastCtrl ? 2 * cx - lastCtrl[0] : cx;
          y1 = lastCtrl ? 2 * cy - lastCtrl[1] : cy;
        }
        const x2 = ox + num(), y2 = oy + num(), x = ox + num(), y = oy + num();
        handles.push([cx, cy, x1, y1], [x, y, x2, y2]);
        lastCtrl = [x2, y2];
        cx = x;
        cy = y;
        anchors.push([cx, cy]);
        continue;
      }
      case 'Q': {
        const x1 = ox + num(), y1 = oy + num();
        const x = ox + num(), y = oy + num();
        handles.push([cx, cy, x1, y1], [x, y, x1, y1]);
        cx = x;
        cy = y;
        break;
      }
      case 'A':
        num(); num(); num(); num(); num();
        cx = ox + num();
        cy = oy + num();
        break;
      default:
        fail();
    }
    lastCtrl = null;
    anchors.push([cx, cy]);
  }
  return { anchors, handles };
}

const attr = (tag: string, name: string): number => {
  const match = new RegExp(`\\s${name}="([^"]+)"`).exec(tag);
  return match ? Number(match[1]) : 0;
};

export function iconPoints(svg: string): Points {
  const anchors: Pt[] = [];
  const handles: Handle[] = [];
  for (const [tag] of svg.matchAll(/<(path|circle|rect|line)\b[^>]*>/g)) {
    if (tag.startsWith('<path')) {
      const d = /\sd="([^"]+)"/.exec(tag)?.[1] ?? '';
      const p = pathPoints(d);
      anchors.push(...p.anchors);
      handles.push(...p.handles);
    } else if (tag.startsWith('<circle')) {
      const [x, y, r] = [attr(tag, 'cx'), attr(tag, 'cy'), attr(tag, 'r')];
      anchors.push([x, y - r], [x + r, y], [x, y + r], [x - r, y]);
    } else if (tag.startsWith('<rect')) {
      const [x, y, w, h, r] = [attr(tag, 'x'), attr(tag, 'y'), attr(tag, 'width'), attr(tag, 'height'), attr(tag, 'rx')];
      anchors.push([x + r, y], [x + w - r, y], [x + w, y + r], [x + w, y + h - r], [x + w - r, y + h], [x + r, y + h], [x, y + h - r], [x, y + r]);
    } else {
      anchors.push([attr(tag, 'x1'), attr(tag, 'y1')], [attr(tag, 'x2'), attr(tag, 'y2')]);
    }
  }
  const key = (p: Pt) => `${p[0].toFixed(3)},${p[1].toFixed(3)}`;
  return { anchors: [...new Map(anchors.map((p) => [key(p), p])).values()], handles };
}

/** The children of the root <svg>, as markup. */
export function innerSvg(svg: string): string {
  return svg.trim().replace(/^<svg\b[^>]*>/, '').replace(/<\/svg>$/, '');
}
```

```ts
/** The exact contents of packages/merki/svg/<name>.svg (mirrors withSize in scripts/lib/optimize.ts, plus its trailing newline). */
export const packageSvg = (svg: string): string => `${svg.replace(/^<svg\b/, '<svg width="16" height="16"')}\n`;

/** What Copy SVG puts on the clipboard: the package file without its trailing newline. */
export const clipboardSvg = (svg: string): string => packageSvg(svg).trimEnd();

export const jsxSnippet = (component: string): string => `<${component} />`;

export function downloadSvg(name: string, contents: string, doc: Document = document, url: typeof URL = URL): void {
  const href = url.createObjectURL(new Blob([contents], { type: 'image/svg+xml' }));
  const anchor = doc.createElement('a');
  anchor.href = href;
  anchor.download = `${name}.svg`;
  doc.body.append(anchor);
  anchor.click();
  anchor.remove();
  url.revokeObjectURL(href);
}
```

```tsx
import { LayoutGridIcon, PencilIcon } from 'merki-icons';
import { useCallback, useEffect, useState } from 'react';
import { Browser } from '../components/Browser';
import { Drawer } from '../components/Drawer';

const fromGrid = () => Boolean((window.history.state as { fromGrid?: boolean } | null)?.fromGrid);

export function Home({ openIcon }: { openIcon: string | null }) {
  const { navigate } = useRouter();
  const [query, setQuery] = useState('');
  const [compact, setCompact] = useState(false);
  const icon = openIcon ? (iconByName.get(openIcon) ?? null) : null;

  const open = (name: string) => {
    setCompact(true);
    // Switching icons while open replaces, so Back always returns to the grid.
    navigate(`/icons/${name}`, { replace: openIcon !== null, state: { fromGrid: true } });
  };
  const move = (name: string) => navigate(`/icons/${name}`, { replace: true, state: window.history.state });

  const close = useCallback(() => {
    const name = openIcon;
    if (fromGrid()) window.history.back();
    else navigate('/');
    if (name) requestAnimationFrame(() => document.querySelector<HTMLElement>(`.cell[data-name="${name}"]`)?.focus({ preventScroll: true }));
  }, [openIcon, navigate]);

  useEffect(() => {
    if (!openIcon) {
      setCompact(false);
      return;
    }
    const onKey = (event: KeyboardEvent) => {
      if (event.key === 'Escape') close();
    };
    document.addEventListener('keydown', onKey);
    return () => document.removeEventListener('keydown', onKey);
  }, [openIcon, close]);

  return (
    <Layout active="index" top={<><Hero /><WallBand /></>}>
      <section id="icons" className="sec" aria-labelledby="icons-title">
        <h2 className="sec-title" id="icons-title"><LayoutGridIcon size={14} className="glyph-blue" />Icons</h2>

      </section>
```

```tsx
import { createElement, type ReactNode } from 'react';

export type Block =
  | { type: 'h'; level: 1 | 2 | 3; text: string }
  | { type: 'p'; text: string }
  | { type: 'ul'; items: string[] };

/** Just enough Markdown for CHANGELOG.md: #–### headings, paragraphs, "- " lists. */
export function parseMarkdown(source: string): Block[] {
  const blocks: Block[] = [];
  let para: string[] = [];
  let list: string[] | null = null;
  const flushPara = () => {
    if (para.length) blocks.push({ type: 'p', text: para.join(' ') });
    para = [];
  };
  const flushList = () => {
    if (list) blocks.push({ type: 'ul', items: list });
    list = null;
  };

  for (const raw of source.replace(/\r\n/g, '\n').split('\n')) {
    const line = raw.trimEnd();
    if (!line.trim()) {
      flushPara();
      flushList();
      continue;
    }
    const heading = /^(#{1,3})\s+(.*)$/.exec(line);
    if (heading) {
      flushPara();
      flushList();
      blocks.push({ type: 'h', level: heading[1].length as 1 | 2 | 3, text: heading[2] });
      continue;
    }
    const item = /^[-*]\s+(.*)$/.exec(line);
    if (item) {
      flushPara();
      (list ??= []).push(item[1]);
      continue;
    }
    if (list && /^\s+\S/.test(raw)) {
      list[list.length - 1] += ` ${line.trim()}`;
      continue;
    }
    flushList();
    para.push(line.trim());
  }
  flushPara();
  flushList();
  return blocks;
}

const INLINE = /(`[^`]+`)|(\*\*[^*]+\*\*)|(\[[^\]]+\]\([^)\s]+\)(?:\))?)/g;
const SAFE_HREF = /^(https?:\/\/|\/|#)/;

export function renderInline(text: string): ReactNode[] {
  const out: ReactNode[] = [];
  let last = 0;
  let key = 0;
  for (const match of text.matchAll(INLINE)) {
    const start = match.index ?? 0;
    if (start > last) out.push(text.slice(last, start));
    const token = match[0];
    if (token.startsWith('`')) out.push(<code key={key++}>{token.slice(1, -1)}</code>);
    else if (token.startsWith('**')) out.push(<strong key={key++}>{token.slice(2, -2)}</strong>);
    else {
      const link = /^\[([^\]]+)\]\(([^)\s]+)\)/.exec(token)!;
      out.push(SAFE_HREF.test(link[2]) ? <a key={key++} href={link[2]}>{link[1]}</a> : link[1]);
    }
    last = start + token.length;
  }
  if (last < text.length) out.push(text.slice(last));
  return out;
}

export function Markdown({ source }: { source: string }) {
  return (
    <>
      {parseMarkdown(source).map((block, i) => {
        if (block.type === 'h') return createElement(`h${block.level}`, { key: i }, renderInline(block.text));
        if (block.type === 'p') return <p key={i}>{renderInline(block.text)}</p>;
        return (
          <ul key={i}>
            {block.items.map((item, j) => (
              <li key={j}>{renderInline(item)}</li>
            ))}
          </ul>
        );
      })}
    </>
  );
}
```
